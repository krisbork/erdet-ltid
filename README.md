# Er det øltid?

## Standard

https://krisbork.github.io/erdet-ltid/

Viser **Ja** fredag fra kl. 14.00. Ellers vises **Nej**.

## Altid ja

https://krisbork.github.io/erdet-ltid/?ja

Parameteren `ja` uden en dato viser altid **Ja**.

## Ja fra et bestemt tidspunkt

https://krisbork.github.io/erdet-ltid/?ja=2026-09-04T18:30

Brug formatet `?ja=YYYY-MM-DDTHH:mm`. Siden viser **Nej** før tidspunktet og **Ja** fra tidspunktet og frem.

Alle datoer og tidspunkter fortolkes i tidszonen `Europe/Copenhagen`.
